# Export and delivery

Before sending a piece, open **Document View** and read the assembled draft. It includes the title and nonempty draft sections in order. Parked thoughts, Storyboard notes, Lab history, alternatives and other private Workbench material are **not** part of a reading copy.

- **Copy whole piece** puts the assembled piece on the clipboard as formatted text where available, with plain text too. Paste into your destination and check its formatting.
- **Download → PDF** makes a reading file. The bundled PDF font cannot represent every character; if it reports an error for your text, use DOCX or Markdown rather than assuming a missing character was exported.
- **Download → Word document (.docx)** makes an editable Word file.
- **Download → Markdown (.md)** makes a clean finished-piece text file, including the title.

Desktop downloads ask you where to save. **Ship / Send → Copy for Notion** is a manual paste, not a connected Notion send. **Download for Obsidian** gives a Markdown file for you to place in your vault; there is no automatic sync or frontmatter.

In **Document actions**, **Copy body as Markdown** intentionally omits the title, useful when a destination already supplies its own heading. **Export Markdown** includes the title as a finished-piece download. **Copy plain text** and **Copy document** are other clipboard choices there.

For a **recoverable writing project**, choose **Export JSON**, not a reading file. Document JSON includes parked sections and document-specific work, but not your global Personal Library, Style DNA, provider settings or credential. **Import JSON** opens a new copy rather than replacing the original. **Manage documents** can export a document-only backup covering active and archived writing, but cannot import that multi-document backup as a batch. Library export is separate. See [Data and backups](data-and-backups.md).
