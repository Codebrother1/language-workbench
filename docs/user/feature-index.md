# Feature Index

The name you half remember, and where to go next. You can also search **Find a tool** in the app with `Cmd/Ctrl+K`.

| Feature                    | What it is for                                                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **AI providers**           | See provider status, add a desktop OpenAI key and choose broader model defaults. [Models and routing](models-and-routing.md)                                             |
| **Archive document**       | Hide a piece from the normal switcher without deleting it; restore it from Manage documents. [Troubleshooting](troubleshooting.md#did-i-delete-a-document-or-archive-it) |
| **Delivery Lens**          | Ask how marks, casing or a short passage may land, without generating a replacement. [Workbench](workbench.md#words-phrases-and-delivery)                                |
| **Document View**          | Read and polish the assembled piece, then copy or download it. [Document View](document-view.md)                                                                         |
| **Find a tool**            | Search existing actions without leaving the writing workspace. [Workbench](workbench.md)                                                                                 |
| **Language Radar**         | Inspect explicitly researched language patterns and decide which to keep or avoid. [Language Radar](language-radar.md)                                                   |
| **Model Compare**          | See separate responses from 2–4 chosen models without picking a winner automatically. [Models and routing](models-and-routing.md#discovery-comparison-and-cost)          |
| **Parked Thoughts**        | Keep editable sections outside the reader draft until you place them back. [Writing a piece](writing-a-piece.md)                                                         |
| **Personal Library**       | Save your own snippets, patterns, moves, examples and guides for later use. [Personal Library](personal-library.md)                                                      |
| **Piece Memory**           | Record the purpose, open questions, decisions and next move for this piece. [Piece Memory](piece-memory.md)                                                              |
| **Revision checkpoint**    | Compare the current draft with one writer-set baseline. [Revision checkpoint](revision.md)                                                                               |
| **Revision Plan**          | Keep section-linked notes about what you want to reconsider. [Revision Plan](revision-plan.md)                                                                           |
| **Semantic section types** | Name a section's job without imposing a fixed outline. [Writing a piece](writing-a-piece.md)                                                                             |
| **Sources**                | Keep reference text apart from the draft so tools can consult it. [Sources](sources.md)                                                                                  |
| **Structure**              | Explore a relation between your own thoughts and stage a human-built proposal. [Workbench](workbench.md#structure-without-a-template)                                    |
| **Style DNA**              | Set broad voice preferences that guide, rather than rewrite, future suggestions. [Style DNA](style-dna.md)                                                               |
| **Takes**                  | Keep a section alternative without replacing today's prose. [Takes](takes.md)                                                                                            |
| **Technical Writing**      | Diagnose the reader's technical-writing problem without generating a template. [Technical Writing](technical-writing.md)                                                 |
| **Word/Phrase Lens**       | Explore a short selection and preview a possible replacement in its sentence. [Workbench](workbench.md#words-phrases-and-delivery)                                       |
| **Workbench**              | Write, label, arrange and park sections. [Workbench](workbench.md)                                                                                                       |
| **Writing Brief**          | Tell the tools what you intend to make, when you know it. [Writing Brief](writing-brief.md)                                                                              |
