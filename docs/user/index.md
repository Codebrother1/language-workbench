# Language Workbench: a writer's guide

Start with a thought, not a configuration screen. [Quick Start](quick-start.md) walks from an empty page to a copy you can share. Nothing needs to be set up before writing.

Language Workbench is closer to a writing timeline than a word processor. In the **Workbench**, you make, move and work on sections. In **Document View**, you read their assembled draft, polish it and copy or download it. Both views work on the **same writing**, not separate versions. Parked thoughts stay in the project but out of the reader draft.

The guiding idea is **“Whatever I touch becomes deeply editable.”** You can write directly, move a section, keep another version, or ask a Lab tool about one passage. AI advises; you decide what, if anything, enters the draft.
