# Personal Library

The **Personal library** is a shelf for language and choices worth keeping across local documents: snippets, patterns, moves, style examples, style rules and connectors. Open it from **Document actions → Personal library**, or **Find a tool**. Save a selection or candidate, or choose **New library item** to enter your own words and a note on why they matter. **My Language** is a flag on an item, not another place your writing is stored.

Saving does **not** insert that item into a draft or teach an AI your style automatically. **Add to Hook Style** (or another section type) saves an example, not a rule inferred from it. To state a rule, use **Style guides → Save style rule** and name the preference yourself. An item can be a reference, a favorite or something to avoid suggesting. A snippet or style example can be **Preview for target**; only an explicit acceptance changes your prose. Copying an item merely copies it.

You can narrow items to section types, content types, audience labels and register. Within one field, any listed value may match; across different fields, all specified restrictions must match. Audience labels need to match exactly (ignoring case); tags help search but are not restrictions. Search finds words and near spellings, not meanings. If a category hides matching items, **Search all types** reveals them. A large library is not guaranteed to fit entirely into a model's request, so check important guidance yourself.

**Library backup & import → Export library JSON** saves this shelf separately from your documents. Import adds new copies, not a replacement of existing entries. See [Data and backups](data-and-backups.md). For broad voice preferences, start with [Style DNA](style-dna.md); for building a relation between two thoughts, the Workbench's **Structure** tool lets you fill your own A/B thoughts and preview a scaffold without applying it. It supplies no facts; **Stage for target** is still only a proposal until accepted.
