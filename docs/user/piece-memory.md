# Piece Memory

**Piece memory** is a place to leave yourself a note about this piece, not another draft or an AI-generated summary. Open it from the header or **Document actions**. You can record the purpose, reader, current question, decisions, unresolved questions, next move (optionally linked to a section) and last session note. For example: “Next move: check whether the second example earns its place.”

When the draft changes after you last updated this memory, the app marks it as needing another look. **Mark reviewed** acknowledges the current draft without changing its prose. A saved next move may also appear above the workspace with a link to its section. Dismissing that reminder hides it for now; the note stays in Piece Memory.

The optional question suggestion looks for an **earlier question you wrote in a saved Lab run**. It is offered for your review, not generated research, and nothing is saved until you accept it. Piece Memory does not replace the [Writing Brief](writing-brief.md) (what you are making), a [Revision checkpoint](revision.md) (baseline for changes), or a [Revision Plan](revision-plan.md) (section-linked intentions).
