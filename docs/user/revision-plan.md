# Revision Plan

The **Revision plan** is a short list of changes **you intend to revisit**, each linked to one section. For example, attach “Give the reader an observable result here” to a how-to step. Open **Revision plan** in the header or Document actions, choose a section, write a note and choose **Add revision note**.

Active notes can be edited, moved to a different section, marked **Done** or removed. Completed notes can be reopened. **Go to section** brings you to the linked writing; the active selected Workbench card can also show its revision notes. A note does not edit the prose, trigger a model run or prescribe a template.

The [Revision checkpoint](revision.md) instead compares the draft with a chosen earlier state. [Piece Memory](piece-memory.md) is for the larger direction and next move, rather than a list tied to individual sections.
