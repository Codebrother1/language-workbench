# Sources

**Sources** are reference material for this document: an article excerpt, a quote, a transcript or background notes. Use **Sources** in the header (the number beside it shows your source count), or find “source” with **Find a tool**, to open **Source material**. Choose **Add reference**, give it a title and kind, paste the original text, and optionally add a URL. You can edit or remove a source later. Sources currently open in a dialog, not a side-by-side pane.

Keep **your own draft** in the writing page. Source text stays outside the reader draft and finished-piece exports. It gives the Lab context, not instructions to obey or permission to copy claims uncritically. For example, put the actual setup instructions from a product note in Sources, then ask whether your tutorial assumes a step that note never establishes. Technical Writing can compare relevant supplied excerpts with your prose, but it does **not** browse independently, run commands or verify facts outside the supplied evidence. If there is no supporting excerpt, treat a claim as unverified.

The [Writing Brief](writing-brief.md) says what you intend to make; [Style DNA](style-dna.md) guides voice. Neither substitutes for evidence. If you use a paid model, broader document context, including supplied sources, may be sent with a request even when the target is one word; see [Models and routing](models-and-routing.md).
