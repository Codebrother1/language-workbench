# Style DNA

**Style DNA** holds the broad voice preferences you want the tools to consider across pieces. Open **Style DNA** in the header to describe voice and cadence, vocabulary and boundaries. You can specify phrases you dislike, how you treat fragments or profanity, and other preferences in your own words. Choose **Save voice preferences** when you are done; leaving the panel without saving does not keep changes to this form.

The same panel has optional **Knowledge packs**, principles you can switch on and edit. They are things to consult, not formulas the draft must follow. A style preference guides a proposal; it does not rewrite existing prose or guarantee that every model choice will sound right.

For a more specific preference, use a [Personal Library](personal-library.md) style guide scoped to a section type or content type. Guidance for a Lab run is read in this order: **current instruction → section Storyboard note → matching section-type guide → matching content-type guide → global Style DNA**. A narrower choice takes priority for named preferences. Freeform guidance still requires your judgment, and you must review every result. This style order is **different from model-routing order**.

You can always keep the sentence you wrote. [Takes](takes.md) let you save an alternative without applying it.
