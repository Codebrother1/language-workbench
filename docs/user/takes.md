# Takes: keep another version

A **Take** is a saved alternative for a section, not another active draft. When a passage feels promising but you want to experiment, choose **Save take** on its selected Workbench card and optionally name it, for example “quieter opening.” The current prose stays where it is. Saved Lab proposals and model comparisons can also become takes; applying an AI proposal keeps the earlier text as an original alternative.

Open a card's saved takes (or its alternatives in the Inspector) to compare a version with the current writing. You can return to a human take using an explicit activation; simply opening or copying it does nothing to the draft. When you activate a human take, an unsaved departing draft is kept as another human take. Activating a proposal or older take checks that its original target still fits; if the passage has changed, the app can refuse rather than guess where to insert it. A Take saves text, not a lossless copy of every rich-format detail.

Use [Revision checkpoint](revision.md) if you want to see what has changed **across the draft** since a writer-chosen baseline. Use [Revision Plan](revision-plan.md) for work you still intend to do. Neither is a Take.
