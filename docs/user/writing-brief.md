# Writing Brief

The **Writing Brief** answers “What are you making?” You can open it before, during or after writing. It is optional: leave unknown fields blank and begin with a sentence instead.

Set a content type and destination if you know them; add audience, objectives, desired reactions, source-material type, desired length and custom constraints as useful. You can also say which frameworks to exclude and whether frameworks are merely references or something you intend to use. For example: “Reader: someone trying this for the first time. Objective: reach the first successful run. Avoid a three-act framing.” The brief helps tools understand your intention; it does **not** create a template or silently change a section.

For actual quoted or technical material, use [Sources](sources.md). For a voice preference that spans pieces, use [Style DNA](style-dna.md); for where you left off in this one, use [Piece Memory](piece-memory.md). The [Technical Writing](technical-writing.md) lens can use the brief to understand the kind of reader task you are describing.
